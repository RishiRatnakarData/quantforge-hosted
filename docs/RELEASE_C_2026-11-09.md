## Integrated user experience

- **Models** is a functioning screen with **Prediction / Risk / Valuation / Strategy Testing** and ordinary **Results / Evaluation / Method** tabs. The company follows Explore; changes to selected issuer and data entitlement invalidate the old experiment. The default screen has no accordion controls.
- **Prediction** uses the existing actual L2-logistic experiment, with bounded five-session past-only features and mature outcomes, expanding chronological tests, held-out accuracy and Brier versus an expanding historical frequency baseline. Release C adds **three descriptive calibration groups and a holdout class-balance indicator**. No retrospective hyperparameter search or calibrated profit forecast is claimed. When private prices are unavailable, prediction is withheld rather than substituted with illustrative prices.
- **Risk** gives 60-session rolling historical annualized price volatility, maximum drawdown, one-day 95% historical VaR/Expected Shortfall, sample-split stability, and a deterministic **circular moving-block bootstrap** sample-sensitivity interval for realized volatility when at least 180 daily returns exist. It is *not* a future volatility/VaR confidence interval. The sample histogram/comparison/risk engines built in Release B remain in Compare and Portfolio Analysis.
- **Valuation** uses annual SEC-derived **operating cash flow minus cash PP&E purchases** as a *cash-flow proxy* and compares 5-year growth/discount/terminal assumptions, including a sensitivity grid. Missing or nonpositive cash flow withholds the estimate. **Neither enterprise value nor equity/share fair value is claimed**, because FCFF and a sourced cash/debt/shares bridge have not been established for the scenario model.
- **Strategy Testing** presents a fixed, lagged 20/60-session price-filter example against price-only buy and hold. Exposures use **the prior close only**; fees apply to switching, the passive benchmark pays an entry fee, and the last third of the available period is described separately. This is an *explanatory historical experiment*, not optimized predictive skill or an executable fill. The separately tested multiple-asset optimization, walk-forward, robustness and factor engines remain preserved.
- **Methods** now provides **Overview / Data / Statistical Methods / Engineering**, with a concise product rationale, genuine SEC XBRL snapshot trace, model-input/assumption/test/limit map, and actual implementation/CI/security links. The old Methods page is retained as hidden compatibility markup temporarily; final retirement belongs to the agreed post-release consolidation.

## Scientific evidence and guardrails

| Question | Implementation | Explicit limitation |
| --- | --- | --- |
| Does historical price direction beat a simple baseline? | `web/site/private_predictive_ml_v180.js` + small descriptive holdout calibration groups | No probability calibration proof, live forecast, or trading P&L |
| How variable were historical prices? | `web/site/research_models_core_v22.js` rolling volatility, VaR/ES, drawdown, block bootstrap | Price-only, sample-dependent; bootstrap is not future coverage |
| How sensitive is a DCF calculation? | `dcfProxy`/`valuation` on SEC cash-flow proxy | Not an equity share-price target or true FCFF DCF |
| Does a predetermined price rule improve historical results? | `strategy` with past-only signals and explicit switch costs | No slippage/dividends, no strategy selection validation, no future profit assurance |
| Can an observed risk result be traced to source? | `web/site/research_app_v20.js` source context; Methods links and source categories | Real market entitlement only after owner acceptance |

All reported SEC financial observations retain missingness, period and filing/provenance rules from the unchanged snapshot and financial-research engines. Public market-path exhibits are **synthetic, deterministic and labeled**. Private price research stays MFA-owner scoped and fails closed when data are unavailable. The shared UI does not publish or persist private observations.
