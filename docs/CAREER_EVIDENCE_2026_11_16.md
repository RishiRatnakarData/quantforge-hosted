Repository access is private; application Methods provides usable explanations and local source paths rather than broken public GitHub file links.

## Five-minute interview route

Start at Home: explain the two modes in one sentence. Public uses real reported SEC financials and labeled synthetic market demonstrations; Private uses eligible observed history behind owner MFA.

1. Open the worked company case in Explore. Show fiscal period versus filing date and one accession. Explain that missing values are not filled with zero.
2. Add a second company and open Compare. Show matched dates and how a strong growth figure does not establish comparability or investment value.
3. Open Prediction Evaluation. Explain the held-out baseline and why a weak result is withheld; contrast this with a scenario, not a forecast, in Valuation.
4. Open Portfolio Analysis. Distinguish hypothetical allocations from saved virtual holdings and contributions from investment gains. Demonstrate current calculations without submitting a transaction.
5. Open Methods Engineering. Trace a result to the data boundary, pure method and specific regression tests. Explain the recovered Pages → Vercel → Supabase deployment and rollback.

Use Public or controlled fixtures in a recorded career demonstration. Do not expose owner balances, notes, email, credentials or provider dashboards. A Private read-only demonstration is optional and requires suitable presentation data. Test counts substantiate implementation checks, not uptime, investment returns or predictive validity.

Portfolio-ready description: “Built a financial research application that connects SEC filing provenance, statistical model evaluation and hypothetical portfolio analysis in a shared public/private interface. Implemented authenticated FastAPI services, MFA-protected versioned state, reproducible static delivery and numerical/security/browser regression checks.”

The project gives experienced reviewers credible methods and source evidence. Recruiter comprehension and real-world decision usefulness still require human review; neither is established by a passing automated test.
