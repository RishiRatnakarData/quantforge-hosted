# QuantForge unified polish release

This release consolidates the protected Decision Center with editorial cleanup, working public methods links, an up-to-date GitHub README, concise navigation, and safer research signal semantics.

## Changes
- Single four-group private navigation. No historical release numbers as private dashboard section titles; internal schema and code version labels remain for reproducibility.
- A clear route back to the public website without a second equally prominent public navigation list while the private workspace is open.
- Decision Center highlights one current research assessment, weighted descriptive screen alignment, method completion, and adverse-versus-missing findings.
- Neutral gray for missing required evidence; green requires evidence-complete integrity. The quantitative models, providers, and risk-policy mechanisms are not changed.
- Optional deep SEC archive import remains under Research Methods; it is not needed for the ordinary screening flow. No automatic claim of remote access to the user's local archive.
- Repaired Research Methods jump links and rewritten README, plus code-level regression tests.

## Exclusions
This is not a replacement for authenticated MFA, Alpaca, note persistence, or real-data browser acceptance. It does not change model schemas, credential management, private APIs, or public market-data sources. Broad code modularization is deliberately deferred because it risks invalidating validated research methods; only the presentation and scoring integrity logic is changed here.

The single installer supports either exact confirmed published V15.0 baseline or a clean published V16.0 FIX1 checkout matching known original source hashes. It stops otherwise.
