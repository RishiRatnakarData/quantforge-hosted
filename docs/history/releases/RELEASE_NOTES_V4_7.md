# QuantForge V4.7 — Company browser

- Browse 259 curated investments by **full name**, ticker, and broad category.
- Popular filter; category filtering; alphabetical rows; text search; **Show more**.
- Company-name autocomplete on Overview and Research; selection opens existing decision analysis.
- Research, watchlist and portfolio show company/fund names in addition to symbols.
- Fictional demo quotes available for all 259 catalog entries, deterministic and clearly labeled. They are *not* current or historical prices.

- Entirely private, local; no credentials needed for demo. The catalog is curated, not every listed security, and does not assert current index membership or tradability.
