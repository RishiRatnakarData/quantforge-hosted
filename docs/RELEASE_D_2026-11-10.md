# QuantForge 2.0 — Release D: shared owner experience and visual consolidation

**Target baseline:** Release C commit `b528a0bff35a986bcfee114e4dda0ad71e786e1c`.

## What is changed

- Retains exactly five visible sections: Explore, Compare, Models, Portfolio, Methods.
- Clickable QuantForge wordmark opens an in-Explore home landing without adding a sixth route or clearing the selected company.
- Replaces the old private-workspace entry path **after MFA** with the same five-section research interface. The sidebar account button opens a focused owner workspace for research notes and virtual positions; note and trade controls also appear contextually in Explore and Portfolio.
- Protected notes and virtual transactions call the existing version-checked `private/notes` and `private/trade` API through the existing authenticated state management. No new credentials, endpoints, storage or real orders.
- Graphite/slate/white-first typography, navigation, cards, tables, desktop/mobile layout, and chart emphasis.
- Public illustrative stock chart is rendered as an **index**, starting at 100 for the selected window, instead of presenting a synthetic dollar quote as an actual issuer price. The CSV keeps market close USD and synthetic index in distinct headers.
- The old private analytics engine and DOM nodes remain compiled for compatibility; the ordinary owner path no longer routes through the four old private destinations. Specialist interface parity and live provider acceptance are **not** claimed solely from this release.

## Trust and accounting boundaries

Public mode: historical SEC Company Facts and deterministic simulated research examples; never a live market quote. Private mode: API-scoped owner/MFA and provider entitlement, with provider outages withholding observed results. Virtual trades use server-validated price observations and modify only an owner-specific virtual ledger. Notes use optimistic version checks and are not stored in public browser storage. The browser never sends orders to a brokerage.

## Verification

- Ruff, `pytest`, Node regressions, deterministic CSP build, public privacy and static audit.
- Chromium Releases A, B and C browser journeys preserved, plus Release D desktop/mobile account-state, home, note, virtual trade and logout journeys with **mocked** authenticated responses.
- Real owner verification is still required for authenticator sign-in and logout, entitled market/news access, persisted note read/write after relogin, virtual position persistence, and Cloudflare/Render parity.

## Known limitations and next evidence

The legacy specialist research calculators remain in the compiled compatibility code but are not yet all individually expressed as streamlined controls in Models and Methods. Public historical market data remains simulated pending redistribution-rights verification. A mocked authenticated browser is not evidence of real provider or Supabase behavior. Review actual end-to-end owner flow, account state, app responsiveness and accessible keyboard interaction before declaring final production acceptance.
