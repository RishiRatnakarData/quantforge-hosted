Model demonstrations and boundaries

Interactive · illustrative

Portfolio simulator

Virtual positions, example prices, rebalancing weights, and estimated fees. Everything stays in the browser session and does not place orders.

Quantitative modeling

Simulated returns, covariance, constrained allocation, and Monte Carlo downside. Results are not calibrated forecasts of market risk.

DCF sensitivity

Illustrative cash-flow assumptions with discounting and terminal-value sensitivity. These are not live company valuations.

Company similarity

Standardized synthetic fundamentals demonstrate nearest-neighbor comparisons. Use SEC Financials for actual company comparisons.

Engineering practices

Architecture and tests

Data engineering

Named SEC issuer identifiers, annual-period filtering, filing cutoffs, input validation, recorded sources and accession details.

Statistical modeling

Constrained optimization, covariance-based portfolio analysis, downside simulation, DCF, and nearest-neighbor feature standardization.

Application engineering

Python backend, static hosted frontend, automated Python and JavaScript checks, continuous integration, and a restrictive script Content Security Policy.

Privacy boundary

Public research data is separate from the owner-only workspace. Private holdings and Alpaca access are protected by authenticated endpoints and authenticator MFA.

The private workspace provides real market observations and virtual trading for the owner only. Public visitors cannot use that API as an open data source.

Historical financial disclosures may be updated or restated. Model scenarios are not investment advice.
